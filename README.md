# Pricify

Live NSE/BSE, crypto and mutual fund tracker

Pricify (pricify.in) is a free market dashboard for Indian users. It tracks 1,700+ stocks across NSE, BSE and global exchanges, 1,250+ cryptocurrencies, ETFs, mutual funds, sectors and IPOs, and includes a SIP calculator and stock screener. Information only, not investment advice.

Website: https://pricify.in/
